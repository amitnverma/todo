Inventory Management

Instructions

- **Search:** Use the search bar to filter inventory items by any attribute. - **Import/Export:** Import inventory data from a CSV file or export the current inventory to a CSV file. - **Add:** Fill out the form with the new item details and click "Add". - **Update:** Modify the details of an existing item and click the "Update" button next to it. - **Delete:** Click the "Delete" button next to an item to remove it from the inventory.
