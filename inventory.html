Instructions

Basic Operations

  • Search: Use the search bar to filter inventory items by any attribute.
  • Add: Fill out the form with the new item details and click "Add Item".
  • Update: Modify the details of an existing item and click the "Update" button.
  • Delete: Click the "Delete" button next to an item to remove it.

CSV Import/Export

The CSV file must have these columns in order:

ecs_name,rds_name,rds_engine,project_name,app_name,app_lead,other_developer_contacts,project_manager,program_name_updated,status,used_by_agencies,azdo_link,operation_technical_design_wiki,technical_design_wiki,application_summary,comments_documentation,comments_alarms,hosted_environment

Notes:

  • ECS Name is required and must be unique
  • Use commas to separate values
  • If a value contains commas, enclose it in double quotes
  • Empty values are allowed for optional fields

Click "Download Template" to get a sample CSV file with the correct format.
